Crea Trip Planner

Crea Trip Planner is a local-first AI travel-planning assistant delivered through Telegram. It helps you build and adjust day-by-day itineraries, remember preferences and constraints, save places of interest, and export plans to PDF or CSV.

The bot and your data run on your own hardware. Planning uses the OpenAI API for reasoning and memory; optional Google Maps Platform APIs can enrich saved places when configured.
